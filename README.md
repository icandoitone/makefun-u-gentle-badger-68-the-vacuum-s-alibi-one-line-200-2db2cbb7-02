## The entry

> That corner is a no-go zone. At 03:12 a Lego brick ambushed me there, and I hold grudges longer than my battery lasts.

## How it works

`main.py` is a deterministic Python 3.13 program using only the standard library. It writes the entry text above — one line, 118 characters — to `/output/entry.txt` (or to the path in the `OUTPUT_PATH` environment variable when set). No network, no randomness, no input: every run produces byte-identical output.

Run it with:

```sh
python3 main.py
```
